Тақырып: Tkinter кітапханасы арқылы графикалық интерфейс құру

Сабақтың мақсаты

  • Tkinter кітапханасымен танысу;
  • Графикалық интерфейс (GUI) құруды үйрену;
  • Терезе, батырма, мәтіндік өріс және жазулармен жұмыс жасау;
  • Python бағдарламаларын қолданушыға ыңғайлы түрде жасау.

1. Tkinter дегеніміз не?

Tkinter — Python тіліндегі графикалық интерфейс (GUI - Graphical User Interface) жасауға арналған стандартты кітапхана.

Бұған дейін біз бағдарламаларды консольде орындадық. Мысалы:


name = input("Атыңызды енгізіңіз: ")
print("Сәлем,", name)

Ал Tkinter көмегімен біз терезелер, батырмалар, мәзірлер және енгізу өрістерін жасай аламыз.

Мысалы:


import tkinter as tk

window = tk.Tk()
window.mainloop()

Бұл код бос терезе ашады.

2. Tkinter кітапханасын қосу

Tkinter кітапханасын импорттау үшін:


import tkinter as tk

Мұндағы:

  • tk — қысқартылған атау;
  • tkinter кітапханасының барлық функциялары мен объектілеріне қол жеткізуге мүмкіндік береді.

3. Терезе құру


import tkinter as tk

window = tk.Tk()

window.title("Менің алғашқы бағдарламам")
window.geometry("400x300")

window.mainloop()

Түсіндірме

Команда Қызметі
Tk() Терезе құрады
title() Терезе атауын өзгертеді
geometry() Өлшемін береді
mainloop() Терезені экранда ұстап тұрады

4. Label (Жазу)

Экранға мәтін шығару үшін қолданылады.


import tkinter as tk

window = tk.Tk()

label = tk.Label(window, text="Сәлем, әлем!")
label.pack()

window.mainloop()

Нәтижесінде терезеде:


Сәлем, әлем!

деген жазу шығады.

5. Button (Батырма)

Батырма жасау:


import tkinter as tk

window = tk.Tk()

button = tk.Button(window, text="Бас")
button.pack()

window.mainloop()

6. Батырмаға әрекет қосу


import tkinter as tk

def hello():
    print("Сәлем!")

window = tk.Tk()

button = tk.Button(window,
                   text="Бас",
                   command=hello)

button.pack()

window.mainloop()

Батырманы басқанда:


Сәлем!

деген жазу консольге шығады.

7. Entry (Енгізу өрісі)

Пайдаланушыдан мәлімет алу үшін қолданылады.


import tkinter as tk

window = tk.Tk()

entry = tk.Entry(window)
entry.pack()

window.mainloop()

8. Entry және Button бірге қолдану


import tkinter as tk

def show_name():
    name = entry.get()
    label.config(text="Сәлем, " + name)

window = tk.Tk()

entry = tk.Entry(window)
entry.pack()

button = tk.Button(window,
                   text="Жіберу",
                   command=show_name)
button.pack()

label = tk.Label(window, text="")
label.pack()

window.mainloop()

Бұл бағдарлама пайдаланушының атын енгізіп, экранға шығарады.

9. Pack() әдісі

Элементтерді терезеге орналастырады.


label.pack()
button.pack()
entry.pack()

Pack() ең қарапайым орналастыру тәсілі болып табылады.

10. Tkinter қолдану салалары

  • Калькулятор жасау
  • Тіркеу жүйесі

  • Ойындар
  • Банк жүйесі
  • Дүкен бағдарламасы
  • Чат бағдарламалары

сияқты көптеген жобалар жасауға болады.

Қорытынды

Tkinter — Python тіліндегі ең қарапайым GUI кітапханасы. Ол арқылы қолданушыға ыңғайлы бағдарламалар жасауға болады.

Tkinter-де ең маңызды элементтер:

  • Tk()
  • Label
  • Button
  • Entry
  • pack()
  • mainloop()

Осы элементтерді меңгергеннен кейін күрделі интерфейстер құруға болады.
